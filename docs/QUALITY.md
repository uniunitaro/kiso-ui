# 品質記録

## 2026年9月24日：Park UI テーマ移行

31色の12段階・透過色、5バリアントの状態色を Park UI のソースから取り込みました。下記の9月7日のコントラスト結果は旧配色の履歴であり、新配色への適合保証ではありません。Park UI の `fg.subtle`（gray.10）や一部の公式バリアントの色は、小さい本文で4.5:1を満たさない場合があります。通常本文は fg / fg.muted、独自の成功・警告本文は12番の色を使います。

2026年9月7日、Windows の Codex in-app Browser で検証しました。レシピの変更をプレビュー側だけで補正せず、コピー元へ反映しています。

今回の検証: typecheck成功、Vitest 79件成功、48部品と使用例および追加パレットのconsumer検証成功、build・format:check成功。ブラウザーで主要部品の6サイズ実寸、ホバー色、ライト／ダーク、390px幅での横はみ出しなし、Dialog内Selectの1500層を確認しました。今回の変更ではaxeの全配色再検査は実施していません。

## ブラウザー

48種類を集めた品質画面で、iris・ocean・forest のライト／ダーク計6通りを検査しました。各配色とも axe の WCAG 2 A/AA・2.1 AA 対象で **違反0件、30ルール通過、手動確認1件**でした。閉じているポップアップの中身までこの数値に含めるものではありません。

手動確認1件は Kbd の単独文字のコントラストです。文字と背景の意味トークンは全6配色で4.5:1以上を数値検証し、実画面も目視確認しました。スクリーンリーダー、Firefox、Safari、実機タッチ操作による網羅的な検証はこの記録には含みません。

320ピクセル幅で、ページ全体と48種類の各プレビューに意図しない横方向のはみ出しがないことを確認しました。表・タブ・ツールバーの必要な横スクロールは、内部の領域へ収めています。390ピクセルのスマートフォン表示も保存しています。

実際に確認した操作:

- Dialog の初期フォーカス、入力、取消、Escape、トリガーへのフォーカス復帰。
- ポータル内への size="lg" の伝播。
- Combobox の検索と選択、Menu の項目実行と Escape。
- 6桁コードの次の欄への自動フォーカスと完了メッセージ。
- Toast の表示、Drawer の表示と終了。
- 縦スライダーの160ピクセルのトラックと矢印キー、縦タブの矢印キーとパネル切り替え。
- 動きを抑える設定で Spinner のアニメーション時間が0.01ミリ秒になること。検証後は設定を解除。
- カタログ検索、モバイルナビゲーション、テーマ切り替え。

## 配布の範囲

プレビューは多数の部品を扱うため、通常の利用アプリより大きな JavaScript を含みます。初回のメインチャンクは gzip 約197KB、追加の複合デモは約55KB、axe は実行時に約160KBを読み込みます。部品のソース／レシピ表示もページごとの遅延読み込みです。コピー先では個別の部品を import し、プレビューや axe は導入しません。

アクセシビリティは、利用側のラベル、配置、内容、状態変化にも依存します。この記録は今回の組み合わせでの検証結果であり、あらゆるアプリへの適合認証ではありません。
